# OmniSpectra Orçamentos

PWA mobile para criação e gerenciamento de orçamentos da OmniSpectra.

## Publicação
Este projeto é um site estático e pode ser publicado diretamente pelo GitHub Pages a partir da branch `main`, pasta raiz (`/`).

## Dados
A versão inicial armazena clientes, catálogo e orçamentos localmente no navegador do aparelho (localStorage). Não inclua chaves, senhas ou dados secretos no repositório.
